# Adaptive Study Dashboard

A beginner-friendly demonstration of an adaptive user interface built with HTML, CSS, and JavaScript.

## Features
- Adjusts study recommendations by experience level and selected study duration.
- Lets users choose normal or larger text.
- Switches between light and dark themes.
- Shows or hides learning hints.
- Updates task completion progress.

## Run the project
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Change the options and mark tasks complete to test the adaptations.

No packages or server are required.

## Important limitation
This is a rule-based personalization demo, not a trained AI model. It demonstrates AI-related adaptive HCI concepts such as context-sensitive adaptation, personalization, feedback, and user control, but it does not perform machine learning or send user data to an AI service. A future version could use a consent-based recommendation model to suggest study plans based on a user's past task completion.

## Source files
- `index.html`: interface structure
- `style.css`: layout, responsive behavior, theme and text size
- `script.js`: adaptation rules and event handling
